A clean, responsive Angular code library website presenting complete lab practical solutions for:
- **PHP** (Scripting with PHP-II Journal Solutions — 30 Programs)
- **GenAI** (Generative AI Practical Solutions — 27 Programs)

Each program includes:
- Clean program title & definition
- Exact source code formatted with syntax highlighting
- One-click copy code functionality

---

## Getting Started

### Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

### Building

To build the project:

```bash
ng build
```

This compiles the project and stores the production artifacts in the `dist/` directory.
