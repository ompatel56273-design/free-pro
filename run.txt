1. PREREQUISITES
--------------------------------------------------------------------------------
Before running or building this application, ensure your environment has:
- Node.js: v20.x or higher (Tested with Node.js v24.21.0)
- npm: v10.x or higher (Tested with npm v11.19.0)
- Angular CLI: v21.x or higher (Tested with @angular/cli 21.2.23)

To check your installed versions, run:
  node -v
  npm -v
  ng version

2. INSTALLING DEPENDENCIES
--------------------------------------------------------------------------------
From the project root directory (where package.json is located), run:
  npm install

This installs all required dependencies including Angular core, common,
compiler, forms, platform-browser, router, and build tools.

3. STARTING THE ANGULAR DEVELOPMENT SERVER
--------------------------------------------------------------------------------
To launch the local Angular development server with hot reload:
  npm start
    -- or --
  ng serve

To specify a custom port or open the browser automatically:
  ng serve --port 4200 --open

4. LOCAL URL TO OPEN IN THE BROWSER
--------------------------------------------------------------------------------
Open your web browser and navigate to:
  http://localhost:4200/

The application will immediately and automatically redirect you to the PHP practicals page:
  http://localhost:4200/php

8. EXECUTION ENVIRONMENT FOR EXTRACTED CODE SNIPPETS
--------------------------------------------------------------------------------
Please note that the code snippets displayed on the website are reference solutions:
- PHP Practical Snippets:
  To run the PHP and HTML code, you need a local web server with PHP and MySQL
  (such as XAMPP, WAMP, or MAMP). Place the files in your web server's htdocs directory
  (e.g., C:/xampp/htdocs/) and start the Apache and MySQL services. For database
  practicals (Program 9), first run the setup.sql script in phpMyAdmin to create the
  LYBCA database and employee table.

- GenAI Python Snippets:
  To run the Python scripts locally, you need Python 3.8+ installed. Install the
  required NLP and Hugging Face dependencies via:
    pip install transformers torch sentencepiece keybert

9. ASSUMPTIONS AND LIMITATIONS
--------------------------------------------------------------------------------
1. Browser Clipboard API:
   The website uses the modern navigator.clipboard API with an automatic textarea fallback
   (document.execCommand('copy')). The Clipboard API requires a secure context (HTTPS or
   http://localhost). If clipboard access is blocked by browser permissions, an error
   toast is shown instructing the user.

2. Syllabus vs Journal Fidelity:
   - Tasks 28, 29, and 30 in the GenAI syllabus ('Self Dev 1, 2, 3') are listed as
     handwritten self-development extensions without code in the source journal PDF.
     They are represented accurately with notice badges rather than fabricating code.
   - In GenAI Program 12, the problem statement specifies English to Hindi translation,
     while the source journal provided Helsinki-NLP/opus-mt-en-fr (English to French).
     The journal code is preserved faithfully, accompanied by an explanatory source note.
   - In GenAI Programs 21, 26, and 27, PDF multi-line model identifiers have been
     consolidated into valid single-line string literals to prevent Python syntax errors,
     with notes detailing the formatting.
